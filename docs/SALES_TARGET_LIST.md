## 営業の進め方（提案）

- **第一波（5社目安、月商5万円目標に対応）は学習塾3〜4社から**：同一業種で複数社が既に生協に出稿している＝チャネルへの投資意欲がある業種と判明している。1社成約できれば同業界への横展開トーク（「他の塾さんも掲載されてますよ」）が使える
- 次点で飲食・医療の個人事業主系（意思決定者が店主本人で早い）。ただし広告予算は塾より小さい可能性
- 株式会社新日本ビジネスアソシエイツ（採用広報業）・株式会社イディー（広告代理店）はリーチの価値をこちらから説明しなくても理解が早いはずだが、逆に「数字が小さい」ことにもシビアな可能性がある。LINE bot友だち数がある程度積み上がってからのアプローチが無難
- 個人契約の家庭教師3件（小5男子／小5女子／中1女子の募集）は企業ではないため対象外

## 第一波：学習塾4社への営業キックオフ（2026-07-30決定）

**進め方（2段階）**：職業安定法「特定募集情報等提供事業」の届出要否がまだ未確認（TODOの専門家相談待ち）のため、**今週は初回コンタクト・関係構築・仮合意にとどめ、正式契約書の締結・入金は届出確認後に行う。**

**価格**：早期契約特典として**月8,000円**（生協の12,000円より約33%安い）。LINE bot本格始動後は10,000〜12,000円の正規価格に移行。3ヶ月契約の場合は追加割引を検討。

**提供価値（2段構え）**：
1. 今すぐ：Discordコミュニティ（300人）への掲載
2. 9月上旬のLINE bot本格始動後：プッシュ通知付きでより広いリーチ

**トーク骨子**：
1. 自己紹介：神戸大学の学生が運営する神大生向け情報サービス「神大ライフハック」
2. 現状を正直に：Discordコミュニティ300人＋LINE botを準備中（9月上旬に本格始動予定、友だち数は現時点ではまだ少ない）
3. 提案：生協より安い月8,000円で、Discord即時掲載＋LINE bot本格始動後の拡大リーチ
4. クロージング：早期契約なら割安価格をロックできるという限定感を出す。ただし**正式合意・入金は届出確認後**である旨は先方にも伝えておく（後出しで揉めないため）

**対象4社**：SSS進学教室／こうべ学習会／ITTO個別指導学院 神戸御影校／志高塾 西宮北口校（連絡先は上表参照）
