## 個票の再抽出SQL

```sql
SELECT sub.id, sub.name, sub.faculty, sub.department, sub.classification, sub.credits
FROM subjects sub
WHERE NOT EXISTS (
  SELECT 1 FROM course_sections cs
  JOIN syllabi sy ON sy.course_section_id = cs.id AND sy.timetable_code IS NOT NULL
  WHERE cs.subject_id = sub.id)
ORDER BY sub.faculty, sub.classification, sub.id;
```
